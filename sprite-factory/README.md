# Sprite Factory

This folder houses the sprite creation pipeline for `Legion`.

## Purpose

Use this area to collect original sprite references, define character style rules, store source sheets, document palettes, and export generated previews.

## Folder Layout

```text
sprite-factory/
  references/       Original reference images created for Legion
  source-sheets/    Working sprite sheets before conversion into code
  palettes/         Palette notes and color ramps
  exports/          Generated preview sheets or review images
  notes/            Sprite construction notes and character-specific specs
```

## Rules

- Only use original assets we own.
- Do not store ripped or copied commercial sprites here.
- Reference screenshots can guide proportions and technique, but production sprites should be original.
- Keep source images at actual pixel size when possible.
- Prefer transparent PNGs for sprite sheets.

## Current Target

Create one original player character sprite sheet first. Once the style is approved, use it as the anchor for all other character sprites.
